Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: applying to the SignPath Foundation programme. Until it is approved, Windows builds are unsigned.

What is signed

Only 1EYE.exe, the Windows desktop app, built from the source in desktop/ by the Windows build workflow on GitHub-hosted runners. Nothing built on a personal machine and no third-party binaries are signed under this certificate.

Privacy

See the privacy policy. 1EYE does not send information to any networked system unless the user asks it to (for example by pressing Go online or adding an AI key).

Uninstalling

1EYE is a portable app with no installer. Close it from Control → Shut down and delete 1EYE.exe and the 1EYE_Data and 1EYE_Shared folders next to it. 1EYE writes nothing else to the system.
